Si instalaste la versión 1.12.1 o 1.12.2 o 1.13.0 y tu tienda presenta un error crítico:

En este caso debes desactivar el plugin manualmente y luego instalar la versión compatible.


Sigue estos pasos:

Accede a los archivos de la instalacion de tu tienda (vía FTP o administrador de archivos del hosting).
Dirígete a la carpeta: wp-content/plugins/transbank-webpay-plus-rest
Elimina la carpeta del plugin.
Con esto podrás volver a acceder al panel de administración de WordPress.
Descarga e instala manualmente la versión compatible (v1.14.0) desde el siguiente enlace, esta versión requiere PHP 8.2
Descargar versión compatible v1.14.0 aquí
