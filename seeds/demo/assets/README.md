# Assets del seed de desarrollo

Archivos estáticos que el script `npm run seed` copia al storage multimedia del backend.

| Ruta | Origen | Uso |
|------|--------|-----|
| `company/logo.png` | `kai-admin/public/logo.png` | Logo de la empresa demo en settings / multimedia |
| `hero-slides/01-calcetines-deportivos.png` | (Gemini / diseño) | Hero slide 1 — calcetines |
| `hero-slides/02-polera-algodon.png` | (Gemini / diseño) | Hero slide 2 — polera |
| `hero-slides/03-toalla-bano.png` | (Gemini / diseño) | Hero slide 3 — toalla |
| `products/` | (Gemini / diseño) | Imagen principal por producto padre |
| `variants/` | (Gemini / diseño) | Imagen por SKU de variante (opcional) |

Al cambiar el logo de la app admin, vuelve a copiarlo aquí antes de ejecutar el seed.

Ver también `products/README.md` y `variants/README.md`.
