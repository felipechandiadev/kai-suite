# Mercado Pago — logos oficiales (2025)

Assets de marca **Handshake** en RGB digital, copiados de la guía Mercado Pago 2025.

| Archivo | Uso recomendado |
|---------|-----------------|
| `MP_RGB_HANDSHAKE_color_horizontal.svg` | Checkout, admin, POS (por defecto) |
| `MP_RGB_HANDSHAKE_color_vertical.svg` | Espacios angostos en vertical |
| `MP_RGB_HANDSHAKE_pluma_horizontal.svg` | Fondos claros / versión pluma |
| `MP_RGB_HANDSHAKE_pluma_vertical.svg` | Fondos claros, vertical |

Copias servidas en cada PWA: `public/integrations/mercado-pago/`.

Componentes React: `MercadoPagoLogo` en pwa-eshop, pwa-admin y pwa-pos.
