## `src/features/` (kai-pos)

Este directorio contiene las features del POS siguiendo el mismo patrón que `kai-admin`:

- UI → Server Actions → Use Cases → Domain (Zod) → Infrastructure (fetch) → Backend

Features iniciales sugeridas (MVP):

- `auth/`
- `session/` (contexto POS + cash session)
- `products/` (búsqueda POS)
- `cart/`
- `checkout/`
- `customers/`
- `payments/`
- `cash/`
